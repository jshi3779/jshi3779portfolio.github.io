ALLEY CAT

面向 TNR 机构与社区居民的城市流浪动物协作平台：让 TNR 的每一步都「被看见」，推动从单点救助走向过程可追踪的社区协同治理。

MY ROLE

个人项目 · 服务设计 / 系统设计 / UI·UX

FOCUS

TNR · Database · Workflow · Community Collaboration · B/C Product

01
问题

协作链路长，数据难统计

抓捕、送医、绝育、照护和放归依赖人工协调，信息散落在群聊与表格；不同组织、医院和志愿者登记口径不一，导致状态更新、统计与追踪困难。

02
设计策略

数据库 + 清晰工作流 + 持续共治

为每只流浪猫建立唯一身份档案，贯通抓捕、绝育、领养、放归与回访；通过线上招募、任务派发和状态同步连接多角色；通过居民上报、投喂记录和领养回访形成长期监测。

03
系统流程

唯一 ID 贯穿 TNR 全流程

剪耳 + 芯片 ID 连接流浪猫档案；地图同步抓捕、绝育与放归状态；TNR 团队、志愿者、动物医院与社区共享数据，沉淀上报、投喂和回访记录。

04
B 端

让组织看见项目、猫与志愿者

工作台包含流浪猫列表与分布地图、项目看板与日历、志愿者名录与状态、社区列表与项目状态，持续同步项目进度。

05
C 端

让居民理解、参与并持续跟进

前台包含首页、流浪猫、聊天与「我的」四个主要模块，覆盖 TNR 项目地图、领养信息、群组沟通和个人志愿记录。
